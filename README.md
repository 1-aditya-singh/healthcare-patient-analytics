# Healthcare Patient Analytics & Risk Analysis System

A data analysis project focused on understanding patient demographics,
disease patterns, healthcare costs, hospital stay duration, risk scores,
and readmission patterns using Python.

---

## Project Overview

Healthcare organizations generate large amounts of patient data containing
information about demographics, diseases, admissions, treatment costs,
hospital stays, and patient risk.

This project analyzes a healthcare patient dataset to identify meaningful
patterns and relationships between these variables.

The project focuses on:

- Data understanding
- Data cleaning
- Exploratory Data Analysis (EDA)
- Descriptive statistics
- Bivariate analysis
- Multivariate analysis
- Correlation analysis
- Statistical hypothesis testing
- Outlier analysis
- Healthcare insights

The analysis is performed using Python-based data analysis and visualization
libraries.

---

## Dataset

The dataset contains **10,000 cleaned patient records** and **16 variables**.

### Main Variables

| Variable | Description |
|---|---|
| patient_id | Unique patient identifier |
| age | Patient age |
| gender | Patient gender |
| blood_pressure | Blood pressure |
| heart_rate | Heart rate |
| bmi | Body Mass Index |
| smoking_status | Smoking status |
| diabetes | Diabetes status |
| hypertension | Hypertension status |
| disease | Primary disease category |
| admission_type | Type of hospital admission |
| length_of_stay | Number of days in hospital |
| medication_count | Number of medications |
| treatment_cost | Treatment cost |
| readmission | Whether the patient was readmitted |
| risk_score | Patient risk score |
